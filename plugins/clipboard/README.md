# Clipboard History

Clipboard history on the ALWM workspace bar.

- Chip shows item count · right-click for quick actions
- **⌘⇧V** toggles the panel
- Click an item (or Enter) to **paste into the frontmost app**
- Search, pin, filters: text / links / image / video / files
- History persists across restarts; passwords (concealed pasteboard) are skipped

Enable under **Settings → Plugins**.
