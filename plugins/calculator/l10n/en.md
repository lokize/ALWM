# Calculator

Full calculator on the ALWM workspace bar.

- Standard + scientific keys (√, x², 1/x, %, ±, parentheses, π, e, sin/cos/tan)
- Memory: MC / MR / M+ / M−
- History with notes, pin, search, and copy
- Keyboard input when the panel is open

Enable under **Settings → Plugins**.
