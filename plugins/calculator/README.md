# Calculator

Full calculator chip for the ALWM workspace bar.

- Standard + scientific keys (√, x², 1/x, %, ±, parentheses, π, e)
- Memory: MC / MR / M+ / M−
- History with optional notes, pin, search, and copy
- Keyboard input when the panel is open
- Persists history under `~/.config/alwm/plugins/dev.alwm.calculator.json`

Enable under **Settings → Plugins**.
