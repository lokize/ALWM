# Pomodoro

Focus timer chip on the ALWM workspace bar.

- Classic pomodoro: focus → short break → long break
- Chip shows remaining time (`25:00`) and phase icon
- Click opens controls (start / pause / skip / reset) and settings
- Optional **keep awake during focus** — same effect as **Prevent Sleep** (idle system + display sleep blocked while a focus session runs)
- macOS notification when a phase ends

Enable under **Settings → Plugins**.
