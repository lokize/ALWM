# Calendário e Tempo

Chip de dia + tempo na barra de workspaces do ALWM.

- O chip mostra ícone do tempo, dia do mês e temperatura atual
- Painel: previsão de 7 dias, localização editável, agenda de hoje e adição rápida
- Notificações opcionais do macOS antes dos eventos

Dados de tempo via [Open-Meteo](https://open-meteo.com/) (sem API key).

Ative em **Ajustes → Plugins**. O macOS pedirá acesso ao Calendário.
