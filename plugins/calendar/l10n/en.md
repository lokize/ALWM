# Calendar & Weather

Day + weather chip on the ALWM workspace bar.

- Chip shows weather icon, day of month, and current temperature
- Panel: 7-day forecast, changeable location, today’s agenda, and quick-add
- Optional macOS notifications before calendar events

Weather data via [Open-Meteo](https://open-meteo.com/) (no API key).

Enable under **Settings → Plugins**. macOS will ask for Calendar access.
