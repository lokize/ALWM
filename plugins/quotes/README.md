# Quotes

FX and crypto quotes on the ALWM workspace bar.

- Watch currency pairs (USD/BRL, EUR/USD, …) via [Frankfurter](https://www.frankfurter.app/) (ECB)
- Watch crypto (BTC, ETH, SOL, …) via [CoinGecko](https://www.coingecko.com/) simple price API
- Optional target alerts (notify when price ≤ target)
- Chip cycles through your watchlist

Enable under **Settings → Plugins**.

Data: `~/.config/alwm/plugins/dev.alwm.quotes.json`
