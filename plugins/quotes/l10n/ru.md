# Котировки

FX и крипто на панели рабочих пространств ALWM.

- Валютные пары (USD/BRL, EUR/USD, …) через Frankfurter (ECB)
- Крипто (BTC, ETH, SOL, …) через CoinGecko
- Опциональные алерты при цене ≤ цели
- Чип циклически показывает список

Включите в **Настройки → Плагины**.

Данные: `~/.config/alwm/plugins/dev.alwm.quotes.json`
