# Cours

Cours FX et crypto sur la barre d’espaces de travail ALWM.

- Paires de devises (USD/BRL, EUR/USD, …) via Frankfurter (BCE)
- Crypto (BTC, ETH, SOL, …) via CoinGecko
- Alertes optionnelles quand le prix ≤ cible
- La puce parcourt votre liste

Activez dans **Réglages → Plugins**.

Données : `~/.config/alwm/plugins/dev.alwm.quotes.json`
