# Cotizaciones

Cotizaciones FX y cripto en la barra de workspaces de ALWM.

- Pares de divisas (USD/BRL, EUR/USD, …) vía Frankfurter (BCE)
- Cripto (BTC, ETH, SOL, …) vía CoinGecko
- Alertas opcionales cuando el precio ≤ objetivo
- El chip cicla tu lista

Activa en **Ajustes → Plugins**.

Datos: `~/.config/alwm/plugins/dev.alwm.quotes.json`
